## 一、已完成能力

| 身份 | 入口与能力 | 验收结果 |
| --- | --- | --- |
| 游客 | 首页、供应大厅、采购大厅、企业展示、供应详情、企业主页 | 六个页面直接打开，无需登录 |
| 游客 | 立即咨询、联系企业、留下需求 | 表单提交生成撮合线索编号；供应关联自动带入产品和企业 |
| 普通注册用户 | 用户名或手机号注册 | 默认 `user` 角色；不能访问企业发布或平台管理接口 |
| 普通注册用户 | 我的咨询、供应收藏 | 登录后可查看本人咨询状态与收藏；游客历史线索不凭手机号自动认领 |
| 企业申请人 | 企业资料、资质名称、展示图 | 申请进入审核中；图片可自行上传替换；审核前不能发布供需 |
| 已认证企业 | 发布供需、查看被分配线索、记录反馈 | API 权限与角色验证通过 |
| 平台管理员 | 线索统计、分配供应企业、跟进、完成 | 浏览器已将测试线索分配至供应企业，状态更新为跟进中 |
| 平台管理员 | 企业与采购需求审核 | 新企业待审核；采购需求发布后先待审核，审核通过才公开 |

本阶段仍按“展示资源 → 留下需求 → 人工撮合”运行。线索不会自动生成订单、支付或物流任务。

## 三、代码与数据变化

- 新增迁移 `services/api/alembic/versions/0003_open_lead_portal.py`，创建 `match_lead`、`lead_followup`、`product_favorite` 三类数据表；原有订单与企业核心表未重构。
- 新增 `services/api/app/api/v1/portal.py` 与注册接口，提供公开留资、本人记录、企业申请、图片绑定、企业线索和运营线索管理。
- 企业审核通过时授予对应企业角色；拒绝时移除企业角色。采购需求发布后进入待审核状态。
- 新增前台咨询、注册、个人中心和后台线索中心页面；供应详情、门户和手机端增加相应入口。
- API 到 Odoo、支付、订单流转、已有生产 Compose 与端口均未改动。
