# 第十师瓜子油料数字化交易平台 · UI 产品化规范

版本：测试迭代版（2026-10-14）  
视觉基准：`I:\瓜子\目标图` 中七张设计图片。目标图保持冻结；新页面和后续改动按对应设计图复核。

## 1. 品牌与文字

- 平台正式名称：**第十师瓜子油料数字化交易平台**；空间有限时可用“瓜子平台”。
- 简短技术支持标识：**技术支持：屯云大数据**。关于系统页使用 **新疆屯云大数据科技有限公司**。
- 不使用“屯云技术”。技术支持放在登录页底部、系统页脚、关于系统与错误提示的次要位置。
- PC、商户端、移动端共用 `static/images/logo/platform-mark.svg`。图标设置 `alt`；纯装饰场合使用空 `alt`。
- 当前为测试迭代阶段，展示数字只读取平台数据库；空数据使用明确的空状态，不编造统计值。

## 2. 色彩

| 用途 | 色值 / 原则 |
| --- | --- |
| 主品牌绿 | `#116c43`，导航、主要按钮、关键链接 |
| 深绿 | `#123d2c`，侧栏与深色底 |
| 浅绿背景 | `#f4f8f6`，页面背景 |
| 卡片底 | `#ffffff` 或半透明浅绿白，避免大块突兀纯白 |
| 边框 | `#dce9df` 左右，使用低对比绿灰 |
| 文字主色 | `#17332a`；说明文字使用灰绿 |
| 交易强调 | 橙色只用于价格、成交与重要交易入口 |

颜色应表达功能层级。状态标签保持成功、警告、危险语义，禁止用高饱和色充满管理页面。

## 3. 字体与节奏

- 中文优先系统字体 `Microsoft YaHei` / `PingFang SC`，数字使用同系易读字体。
- 页面标题 PC 22–28px，移动端 20–24px；区块标题 17–22px；正文 13–15px；辅助信息不小于 11px。
- 基础间距按 4px 的倍数组织：卡片内 16–24px、卡片之间 12–20px、表单项之间 12–16px。
- 价格与统计数字保留充足对比和字重，单位及辅助说明分级显示。

## 4. 组件

- 主要按钮使用品牌绿、8px 左右圆角、柔和阴影与明确 hover；交易行动可用少量橙色。次要按钮用细边框。
- 卡片使用 12–16px 圆角、浅边框或轻阴影；后台减少重复 Banner，优先放指标、状态、表格与简洁图示。
- 标签用 6px 左右圆角、浅底深字；不要只靠颜色表达状态。
- 输入框与选择框统一 8px 左右圆角，保留清晰焦点反馈。
- 图标优先使用同一套线性图标；不混用 Unicode 符号、彩色 emoji 与线性图标。
- 对话框 PC 最大宽度按表单内容设置；窄屏保留 12px 以上屏幕边距，双列表单转单列。
- 空状态说清当前结果和下一步操作；错误状态给出返回、重试或技术支持路径。

## 5. 图片与资源

```text
apps/admin-web/public/static/images/
├── logo/      平台标识
├── banner/    仅首页/登录等有明确展示用途的横幅
├── avatar/    头像
├── icons/     自有图标
└── common/    公共内容配图
```

- 已有 `/demo/*.png` 是当前数据库与 API 回退路径的兼容资产，不迁移或删改其 URL；变更前需先完成引用映射和数据库引用核对。
- 企业无上传照片时显示品牌身份块，不把同一张园区照片冒充多个企业。管理员上传的真实照片仍正常展示。
- 商品图片保持 `object-fit: cover` 和稳定宽高比；内容列表图片使用 `loading="lazy"`、`decoding="async"`。
- 后台每个页面原则上只保留一个主要产业场景区域；其他区域用信息卡片、图标和实际业务数据。
- 新上传素材优先提供适合展示尺寸的 WebP/AVIF 衍生图并保留原图；当前 demo PNG 路径仍是兼容约束，迁移应单独验收。

## 6. 响应式与验收

- 必测宽度：1920×1080、1366×768、390×844。
- 不允许页面级横向溢出；宽表格在自身容器内滚动，统计描述在窄屏改为单列。
- 按钮、输入、弹窗在 390px 下要保留可点击尺寸与可读标签；图片不拉伸变形。
- 截图要分别覆盖登录、首页、交易大厅、工作台、空状态、错误状态、移动 H5 与关键弹窗。
- 每次发布后检查浏览器控制台、图片加载、页面宽度、登录跳转及健康接口。
