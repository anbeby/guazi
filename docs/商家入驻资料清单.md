# 第十师瓜子油料数字化交易平台商家入驻资料清单

适用对象：加工、贸易、采购、仓储等拟入驻企业。当前演示版由平台管理员录入并审核企业资料；商家暂不能从公开页面自行提交入驻申请。

## 一 先提供企业基本信息

| 信息 | 商家准备内容 | 当前系统要求 |
| --- | --- | --- |
| 企业名称 | 与营业执照一致的全称 | 必填 |
| 企业类型 | 加工或贸易等商家、供应商、采购商；由平台选择对应角色 | 必选 |
| 统一社会信用代码 | 18 位代码 | 目前可空，建议入驻审核时提供；填写时系统校验格式和重复 |
| 法定代表人 | 姓名 | 建议提供 |
| 注册资本 | 营业执照登记金额，单位万元 | 选填 |
| 经营范围 | 瓜子油料加工、贸易、采购、仓储等实际经营内容 | 建议提供 |
| 行政区划和详细地址 | 所在地区、注册地址或主要经营地址 | 建议提供 |

企业编码由平台自动生成，商家无需编制。

## 二 指定日常联系人

- 联系人姓名和手机号码：建议提供一名能处理入驻、订单与结算事项的负责人。系统对已填写的手机号校验 11 位格式。
- 电子邮箱：用于业务沟通，当前为选填。
- 商户账号使用人：提供拟使用系统的姓名和手机号；账号由平台管理员另行开通，不需要商家提交现有密码。

## 三 准备经营与展示材料

- 营业执照清晰扫描件或照片，供平台审核原件与登记信息。
- 企业厂区、加工车间、仓储或门店实景图一张，作为企业展示图。管理员可在商户档案中更换。
- 如入驻园区，说明拟入驻园区及档口需求；具体档口分配、合同由平台另行办理。
- 供应商上架商品时，再准备商品名称、分类、规格、等级、产地、年份、包装、计量单位、报价、库存及商品照片。商品资料属于入驻后的上架环节。

## 四 结算资料

- 开户银行名称。
- 银行账户开户名，应与实际结算主体一致。
- 银行结算账号。

当前入驻表单将上述结算信息列为选填；开展真实交易结算前应由平台与企业核对。演示版只登记回款和对账信息，不自动划转资金。

## 五 平台办理顺序

1. 商家交付上述资料，平台管理员核对企业身份、联系人和经营范围。
2. 管理员录入企业档案，选择企业类型和所属园区；系统生成待审核记录。
3. 有审核权限的管理员审核通过后，按需开通商户账号。
4. 按需分配园区档口并办理合同；供应商再录入商品、图片和库存。

**当前演示版办理提示：**营业执照上传控件已存在，但上传结果尚未自动关联到企业档案。审核人员应另行核对并留存执照材料，不能仅凭页面显示“上传成功”认定资料已归档。此项列入后续修复清单。
