## 发布与中止原因

1. 停止瓜子 API 和 worker，备份正式库。
2. 使用 V1.1 镜像执行 Alembic `0001 → 0002 → 0003`，迁移成功；企业数量仍为 18。
3. 把正式 Compose 指向 V1.1 镜像，并移除会覆盖新版移动页的旧静态文件挂载。配置检查通过。
4. 启动新 API/worker 时，Docker Compose 返回容器名冲突：`/gz-api`、`/gz-worker` 已被旧容器占用。现有容器的 Compose 项目名为 `guazi`，此次命令未指定 `-p guazi`，因此尝试以另一项目创建同名容器。**按发布指令立即停止，不继续修复并重试。**新 API、worker 和前端镜像均未在正式服务启动。
